# 入境旅游服务标准互认

管理入境旅游服务标准、认证证据和跨境互认标识。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括东盟旅行社、国内景区、支付机构、接待企业、行业协会、认证机构和旅游主管部门。

资料所依据的领域事实如下：

- 便利化活动探索入境旅游服务标准化发展路径
- 参会方来自主管部门、东盟行业协会、金融机构和文旅企业
- 跨境支付与数字文旅属于核心议题

互认标识的管理要求如下：

- 服务标识标明多语种接待、支付帮助、应急联络的适用地区与有效时段，不混用各企业自我声明
- 行业协会组织东盟旅行社、国内景区、支付机构和接待企业开展互认
- 服务条款、语言版本、证据要求、认证机构与现场核验结果按适用地区关联
- 供应商提交对应版本材料后才能获得有限范围的标识，企业可查看差距并整改
- 主管部门能够区分自我声明、第三方认证与正式互认
- 标准修订、认证暂停、抽查不合格、机构退出或跨境关系撤销时，所有在售产品必须准确更新
- 从原标识可追到核验记录和责任主体

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、服务承诺、互认级别、变更触发、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。

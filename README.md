# 入境旅游服务标准互认

管理入境旅游服务标准、认证证据和跨境互认标识。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括东盟旅行社、国内文旅企业、行业协会、旅游主管部门。

资料所依据的领域事实如下：

- 便利化活动探索入境旅游服务标准化发展路径
- 参会方来自主管部门、东盟行业协会、金融机构和文旅企业
- 跨境支付与数字文旅属于核心议题

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
